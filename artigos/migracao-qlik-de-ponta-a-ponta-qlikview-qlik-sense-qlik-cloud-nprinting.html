Migração Qlik de Ponta a Ponta: QlikView → Qlik Sense → Qlik Cloud + NPrinting

A Qlik anunciou o fim do suporte ao QlikView para 2025. O NPrinting não tem roadmap de evolução. O Qlik Sense on-prem está em modo de manutenção. Empresas que construíram seu BI nos últimos 15 anos sobre QlikView estão diante de uma migração em três etapas — cada uma com suas próprias armadilhas técnicas.

Trilha 1: QlikView → Qlik Sense

NullAsValue e SET NULLINTERPRET precisam ser declarados explicitamente. Section Access reescrito: NTNAME substituído por USER.EMAIL, campo OMIT descontinuado. Grid Charts, Multi-Box e macros VBScript não existem no Sense.

Trilha 2: Qlik Sense On-Prem → Qlik Cloud

Novo modelo de Spaces (Personal, Shared, Managed, Data). Autenticação migra de API Keys para OAuth 2.0. QVDs precisam ir para cloud storage (S3, ADLS Gen2). Extensions legado precisam de re-certificação.

Trilha 3: NPrinting → Qlik Cloud Reporting

NPrinting não tem suporte ao Qlik Cloud. Bursting agora é imperativo via Qlik Application Automation. Templates Office não importam diretamente. NewsStand substituído por Managed Space.
