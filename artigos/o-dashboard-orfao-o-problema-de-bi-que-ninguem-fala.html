A Cena

Quem é o Dono Desse Dashboard?

"Reunião de governança. Alguém compartilha a tela e mostra um dashboard que aparece nos relatórios de uso toda semana. Pergunta simples: quem é o dono disso? Silêncio. Todo mundo olha para o lado. O dashboard tem dois anos, gera 400 views por mês, e ninguém sabe quem o criou."

Isso não é exceção. É a regra na maioria dos tenants Power BI que já auditei.

Cada sprint entrega novos dashboards. Cada analista que sai da empresa deixa relatórios para trás. Cada projeto piloto vira conteúdo permanente sem que ninguém tenha tomado essa decisão conscientemente.

O resultado é um cemitério de dados disfarçado de biblioteca de conhecimento.

Os 5 Sinais de que Seu Tenant Está Fora de Controle

  • ✗Mais de 50 workspaces criados sem naming convention definido
  • ✗Datasets sem endorsement (nem Promoted, nem Certified) em uso por múltiplos relatórios
  • ✗Relatórios com última atualização há mais de 90 dias ainda sendo acessados
  • ✗Nenhum processo formal de descontinuação de conteúdo
  • ✗Contato de owner ausente ou desatualizado nos metadados do workspace

Se você marcou 3 ou mais, sua empresa não tem um problema de Power BI. Tem um problema de governança de conteúdo.

Diagnóstico

A Cultura do "Cria e Esquece"

O problema não é técnico. É cultural e organizacional. As empresas investem em criar dashboards. Não investem em mantê-los ou descontinuá-los.

O dashboard órfão é o sintoma. A causa raiz é a ausência de um processo de ciclo de vida para conteúdo BI.

Segundo a Forrester, empresas têm em média 40% do conteúdo BI abandonado ou desatualizado em seus ambientes. Esse conteúdo não é neutro: ele gera ruído, confusão e desconfiança nos dados.

A Solução

Arquitetura de Ownership: Cada Dashboard Tem um Dono

A solução não é restringir a criação de conteúdo. É criar um sistema onde cada ativo de BI tem responsável, ciclo de vida e critério de descontinuação.

As 4 Camadas da Governança de Conteúdo

1
Workspace Governance Structure Naming convention obrigatório: [Area]-[Finalidade]-[Ambiente]. Ex: Comercial-Pipeline-Prod. Sem isso, nenhum workspace é criado.
2
Endorsement como Contrato de Qualidade Promoted: revisado pelo time. Certified: aprovado pelo CoE de dados. Sem endorsement: conteúdo experimental, não usar em decisões críticas.
3
Data Owner + Report Owner Definidos Todo dataset tem um Data Owner (responsável pelo dado). Todo relatório tem um Report Owner (responsável pela análise). Ambos registrados no workspace.
4
Ciclo de Vida com Data de Revisão Todo conteúdo nasce com uma data de revisão obrigatória (90 ou 180 dias). Na revisão: manter, atualizar ou arquivar. Sem revisão, o conteúdo é marcado como deprecated automaticamente.

O Script de Auditoria do Tenant

PowerShell + Power BI REST API - inventário de conteúdo órfão 
# Conectar ao Power BI
Connect-PowerBIServiceAccount

# Listar todos os workspaces
$workspaces = Get-PowerBIWorkspace -All -Scope Organization

foreach ($ws in $workspaces) {
    $reports = Get-PowerBIReport -WorkspaceId $ws.Id

    foreach ($report in $reports) {
        [PSCustomObject]@{
            Workspace    = $ws.Name
            Report       = $report.Name
            DatasetId    = $report.DatasetId
            # Verificar se tem owner definido nos metadados
            # Verificar data de última atualização
            # Verificar se dataset tem endorsement
            LastRefresh  = $report.ModifiedDateTime
            IsOrphan     = ($ws.Users.Count -eq 0)
        }
    }
} | Export-Csv "audit-bi-tenant.csv" -NoTypeInformation

Plano de Ação

O Que Fazer Esta Semana

Governança de conteúdo não começa com uma plataforma nova. Começa com uma decisão e uma planilha.

  • 1Exporte a lista de todos os workspaces e relatórios do seu tenant via API ou Admin Portal
  • 2Para cada workspace: identifique o owner atual. Se não existir, marque como órfão
  • 3Filtre relatórios sem views nos últimos 90 dias: esse é seu candidato a arquivamento
  • 4Defina a política de endorsement: o que precisa de Promoted? O que precisa de Certified?
  • 5Estabeleça a regra: nenhum workspace novo sem naming convention e owner definido no ato da criação

Um tenant limpo não é utopia. É o resultado de um processo deliberado e repetido. A maioria das empresas nunca fez a primeira auditoria. Você pode fazer essa semana.
