End-to-End Qlik Migration: QlikView → Qlik Sense → Qlik Cloud + NPrinting

Qlik announced end of support for QlikView in 2025. NPrinting has no meaningful roadmap. Qlik Sense on-prem is in maintenance mode. Companies that built their BI on QlikView over the last 15 years are facing a three-stage migration — and each stage has its own technical traps.

Path 1: QlikView → Qlik Sense

NullAsValue and SET NULLINTERPRET must be declared explicitly. Section Access fully rewritten: NTNAME replaced by USER.EMAIL, OMIT field discontinued. Grid Charts, Multi-Box and VBScript macros do not exist in Sense.

Path 2: Qlik Sense On-Prem → Qlik Cloud

New Spaces model (Personal, Shared, Managed, Data) replaces Streams. Authentication migrates from API Keys to OAuth 2.0. QVDs must move to cloud storage (S3, ADLS Gen2). Legacy extensions require re-certification.

Path 3: NPrinting → Qlik Cloud Reporting

NPrinting has no support for Qlik Cloud. Bursting is now imperative via Qlik Application Automation. Office templates do not import directly. NewsStand replaced by Managed Space with controlled access.
