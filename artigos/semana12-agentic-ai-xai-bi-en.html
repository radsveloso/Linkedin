In 2026, two trends dominate conversations about artificial intelligence applied to data: Agentic AI (systems that act autonomously) and Explainable AI / XAI (systems that justify their decisions). Each has standalone value. Together, they solve the biggest historical problem in enterprise BI: speed without sacrificing trust.

In this article, I'll show what each approach means in practice, with real code examples, architectures, and use cases in tools like Qlik, Power BI, and Python.

Part 1: Agentic AI in BI

Agentic AI is not simply a copilot that answers questions. It's a system that perceives the environment, makes decisions, and executes actions autonomously — without requiring a human to formulate each query.

What changes in practice?

Traditional BI

Analyst opens the dashboard every morning, checks KPIs, notices sales dropped 12%, manually investigates, finds the cause hours later, generates a report, and sends it to the manager.

BI with Agentic AI

Agent continuously monitors KPIs, detects a 12% sales drop at 2:17 AM, automatically identifies the root cause (logistics failure in the South region), creates a summary, and notifies the manager before 7:00 AM.

Architecture of an Autonomous BI Agent

-- Autonomous BI Agent Flow -- [DATA SOURCES] Qlik Cloud / Power BI Dataset / Data Warehouse | v [PERCEPTION LAYER] Agent monitors KPIs via API or webhook Dynamic threshold (moving average + standard deviation) | v [DECISION ENGINE] [CONTEXTUAL MEMORY] Analyzes anomaly <--- Incident history Prioritizes severity Known seasonality Selects action Business rules | v [EXECUTION LAYER] - Runs investigation query - Correlates with other metrics - Generates explanatory narrative | v [OUTPUT] Alert + Context + Suggested Action -> Slack / Email / Teams

Practical example: Monitoring agent with Python

Below is a functional example of how to implement a simple agent that monitors a metric via the Qlik API and triggers alerts with context:

Python - Monitoring Agent
import requests
import statistics
from datetime import datetime, timedelta

class BIAgent:
    def __init__(self, qlik_api_url, auth_token, slack_webhook):
        self.api_url = qlik_api_url
        self.headers = {"Authorization": f"Bearer {auth_token}"}
        self.slack_webhook = slack_webhook
        self.memory = {}  # Metrics history

    def fetch_kpi(self, metric_name: str, days_back: int = 30) -> list:
        """Fetches KPI history via Qlik REST API"""
        end_date = datetime.now()
        start_date = end_date - timedelta(days=days_back)

        response = requests.get(
            f"{self.api_url}/metrics/{metric_name}",
            headers=self.headers,
            params={
                "startDate": start_date.isoformat(),
                "endDate": end_date.isoformat()
            }
        )
        return response.json()["values"]

    def detect_anomaly(self, values: list, sensitivity: float = 2.0) -> dict:
        """Detects anomalies using dynamic z-score"""
        if len(values) < 7:
            return {"is_anomaly": False}

        recent = values[-1]           # Current value
        baseline = values[:-1]        # Historical data

        mean = statistics.mean(baseline)
        stdev = statistics.stdev(baseline)

        if stdev == 0:
            return {"is_anomaly": False}

        z_score = (recent - mean) / stdev
        pct_change = ((recent - mean) / mean) * 100

        return {
            "is_anomaly": abs(z_score) > sensitivity,
            "direction": "drop" if recent < mean else "spike",
            "z_score": round(z_score, 2),
            "pct_change": round(pct_change, 1),
            "current_value": recent,
            "expected_value": round(mean, 2)
        }

    def investigate(self, metric_name: str, anomaly: dict) -> str:
        """Investigates root cause by correlating metrics"""
        correlations = []
        related_metrics = ["conversion", "traffic", "inventory", "logistics"]

        for related in related_metrics:
            values = self.fetch_kpi(related, days_back=7)
            if values:
                delta = ((values[-1] - values[-2]) / values[-2]) * 100
                if abs(delta) > 5:  # Significant change
                    correlations.append(f"{related}: {delta:+.1f}%")

        context = f"""
Anomaly detected in {metric_name}:
- Change: {anomaly['pct_change']:+.1f}% ({anomaly['direction']})
- Z-score: {anomaly['z_score']} (sensitivity: 2.0 sigma)
- Current value: {anomaly['current_value']}
- Expected value: {anomaly['expected_value']}

Correlated metrics with significant changes:
{chr(10).join(correlations) if correlations else "No significant correlations found"}
        """
        return context.strip()

    def alert(self, metric_name: str, investigation: str):
        """Sends structured alert to Slack"""
        payload = {
            "text": f":rotating_light: *Anomaly detected: {metric_name}*",
            "blocks": [
                {
                    "type": "section",
                    "text": {
                        "type": "mrkdwn",
                        "text": f"*BI Agent detected anomaly*\n```{investigation}```"
                    }
                }
            ]
        }
        requests.post(self.slack_webhook, json=payload)

    def run(self, metrics_to_monitor: list):
        """Main agent loop"""
        for metric in metrics_to_monitor:
            values = self.fetch_kpi(metric)
            anomaly = self.detect_anomaly(values)

            if anomaly["is_anomaly"]:
                investigation = self.investigate(metric, anomaly)
                self.alert(metric, investigation)
                print(f"[{datetime.now()}] Alert sent for {metric}")

Integration with Qlik via MCP Server

If you've already configured the Qlik MCP Server (see Week 11's article), you can use Claude as the agent's reasoning engine directly:

Example - Qlik MCP + Claude as Agent
import anthropic

client = anthropic.Anthropic()

def analyze_with_claude(metric_data: dict) -> str:
    """Uses Claude to analyze anomaly and generate explanation"""

    prompt = f"""
    You are a BI agent. Analyze the data below and:
    1. Identify whether there is an anomaly
    2. Suggest the 3 most likely causes in order of probability
    3. Recommend an immediate action
    4. Estimate the financial impact if left unaddressed

    Qlik Cloud data:
    {metric_data}

    Respond directly and structured for a business manager.
    """

    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=500,
        messages=[{"role": "user", "content": prompt}]
    )

    return response.content[0].text

Part 2: Explainable AI (XAI) - The BI that accounts for itself

Agentic AI solves speed. XAI solves trust. Without explainability, an autonomous agent is a black box — and no serious executive will trust decisions they can't audit.

XAI is not about showing code or technical logs. It's about answering: "Why did the system reach this conclusion?" in language any stakeholder can understand.

The 3 levels of explainability in BI

Level What it explains For whom Example
Global How the model works overall Data team General feature importance of the predictive model
Local Why this specific prediction was made Analyst / Manager "This sale was classified as churn because NPS < 6 and inactivity > 45 days"
Counterfactual What would change to get a different result Business team "If NPS were 7+, churn probability would drop to 18%"

XAI in practice: SHAP with BI data

SHAP (SHapley Additive exPlanations) is the most widely adopted technique for explainability in ML models. Here's how to use it with BI data:

Python - SHAP to explain Churn predictions
import shap
import pandas as pd
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier

# Customer data (simulated - equivalent to what would come from Qlik/Power BI)
df = pd.DataFrame({
    'nps_score':         [8, 3, 7, 2, 9, 4, 6, 1],
    'days_inactive':     [5, 60, 10, 75, 3, 45, 20, 90],
    'open_tickets':      [0, 5,  1,  8,  0,  3,  1, 10],
    'feature_usage_pct': [85, 20, 70, 10, 95, 35, 60, 5],
    'contract_value':    [5000, 800, 3200, 400, 8000, 1200, 2500, 300],
    'churn':             [0, 1, 0, 1, 0, 1, 0, 1]
})

X = df.drop('churn', axis=1)
y = df['churn']

# Train model (simplified for demonstration)
model = GradientBoostingClassifier(n_estimators=100, random_state=42)
model.fit(X, y)

# Create SHAP explainer
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X)

# --- GLOBAL EXPLANATION (feature importance) ---
print("=== Global Feature Importance ===")
feature_importance = pd.DataFrame({
    'feature': X.columns,
    'importance': np.abs(shap_values).mean(axis=0)
}).sort_values('importance', ascending=False)
print(feature_importance.to_string(index=False))

# Expected output:
#          feature  importance
#     days_inactive    0.3821
#         nps_score    0.2945
#  feature_usage_pct   0.1823
#      open_tickets    0.1234
#    contract_value    0.0177

# --- LOCAL EXPLANATION (per specific customer) ---
def explain_prediction(client_idx: int, df: pd.DataFrame,
                        shap_values, threshold: float = 0.5) -> str:
    """Generates human-readable explanation for a specific customer"""
    prediction_prob = model.predict_proba(X.iloc[[client_idx]])[0][1]
    prediction = "CHURN" if prediction_prob >= threshold else "ACTIVE"

    client_shap = shap_values[client_idx]
    feature_impact = sorted(
        zip(X.columns, client_shap),
        key=lambda x: abs(x[1]),
        reverse=True
    )

    explanation = f"""
[Customer #{client_idx}] Prediction: {prediction} ({prediction_prob:.0%} churn prob.)

Key drivers:
"""
    for feat, impact in feature_impact:
        direction = "increased" if impact > 0 else "reduced"
        val = df.iloc[client_idx][feat]
        explanation += f"  - {feat} = {val} -> {direction} risk ({impact:+.3f})\n"

    if prediction == "CHURN":
        explanation += "\nTo reduce risk: improving NPS score and reducing inactivity days would have the highest impact."

    return explanation.strip()

# Test for at-risk customer (index 1)
print(explain_prediction(1, df, shap_values))

# Expected output:
# [Customer #1] Prediction: CHURN (89% churn prob.)
# Key drivers:
#   - days_inactive = 60 -> increased risk (+0.412)
#   - nps_score = 3 -> increased risk (+0.318)
#   - feature_usage_pct = 20 -> increased risk (+0.195)
#   - open_tickets = 5 -> increased risk (+0.143)
#   - contract_value = 800 -> reduced risk (-0.028)
# To reduce risk: improving NPS score and reducing inactivity days would have the highest impact.

XAI in the context of Qlik and Power BI

Qlik AutoML + XAI

Qlik AutoML (Qlik Cloud) already includes native SHAP in generated models. You see feature importance and can export explanations as calculated fields to use in visualizations.

Power BI + Azure ML

Integration via Azure Machine Learning allows bringing SHAP explanations as columns in a Power BI table. DAX can then format these explanations into tooltips and narratives.

The combination: Agentic AI + XAI together

The real power emerges when the autonomous agent is required to justify every action it takes. Here's the complete flow:

1

Autonomous perception

Agent detects 18% drop in South region sales at 3:42 AM

2

Correlated investigation

Cross-references logistics (-23%), weather (heavy rain), similar date history, and regional NPS

3

Automatically generated explanation

XAI calculates each factor's contribution: logistics (47%), weather (31%), seasonality (14%), other (8%)

4

Action + Narrative

Agent notifies manager with: identified cause, estimated impact ($42K), suggested action, and analysis confidence (87%)

5

Feedback loop

Manager confirms or refutes the cause. Agent learns and adjusts the model for next time.

Conclusion

BI in 2026 is not about building prettier dashboards. It's about building systems that perceive, act, and explain — while the analyst focuses on validating, refining, and making strategic decisions based on that output.

Agentic AI without XAI is dangerous: you don't know why the system did what it did. XAI without Agentic AI is slow: you have the explanations but need to ask the right questions. Together, they form the most powerful BI stack available today.

  • Start by configuring smart alerts with dynamic z-score — not fixed thresholds
  • Add SHAP to your most critical predictive model and show explanations in the dashboard
  • Experiment with the Qlik MCP or Claude API to add reasoning to your pipeline
  • Document every autonomous agent decision for auditing — XAI makes this practical
