Fundamentals

What is MCP and why does it matter for data?

Today I connected my AI agent directly to LinkedIn — no browser, no copy-paste, no API keys buried in code. I just said: "publish this article" → and it did. That's MCP in action.

The Model Context Protocol is an open standard created by Anthropic that works like a "USB-C for AI" — a universal connector enabling any language model to communicate with external tools in a standardized way.

Anthropic, Microsoft, Google, and AWS are all on board. MCP is becoming the industry standard for AI integration with external systems.

Practical Application

What does a BI analyst actually gain?

Imagine your AI agent autonomously doing all of this:

  • ✓
    Query Qlik Sense and auto-generate analyses

    Open Jira tickets when dashboard anomalies are detected

Roadmap 2026

What's coming — and why it impacts data pipelines

The MCP steering committee published their roadmap in March 2026 with three critical changes:

1

Tasks Primitive — Async Operations

An agent can dispatch a 20-minute ETL pipeline and poll for completion without blocking the session. Essential for real production pipelines.

2

Stateless HTTP Transport

Cloud deployment dramatically simplified. Less overhead, more scale. Perfect for AWS Lambda and Google Cloud Run serverless environments.

3

Built-in Compliance & Governance

Alignment with global compliance frameworks — critical for financial, healthcare, or GDPR/CCPA-regulated environments.

Getting Started

How to set up your BI agent with MCP

In under 30 minutes you can have an agent connected to your tools. Here's the Claude Desktop config:

claude_desktop_config.json
// MCP Server configuration in Claude Desktop { "mcpServers": { "linkedin": { "url": "http://localhost:3000/sse" }, "qlik": { "url": "http://localhost:3001/sse" }, "power-bi": { "url": "http://localhost:3002/sse" } } }

Now you can ask the agent: "Based on this dashboard, write a technical post about the anomaly we found and publish it to LinkedIn." And it does. In seconds.
